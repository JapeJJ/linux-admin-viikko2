Database

MySQL is running on the same server.It only accepts a connection from localhost. The app uses laskuri database, and mySQL starts automatically when the server boots.

How the counter is stored

Python app tells mySQL to add 1 to the count, then asks mySQL for the current count and inputs it to HTML. mySQL saves data to a disk, so the number doesn't reset after a server restart.
